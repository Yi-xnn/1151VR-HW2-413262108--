### 1.建立場景物件：在Unity場景中建立一個2D物件作為角色，並將初始位置放在起點。

### 2.建立並掛載腳本：在專案中新增名為PlayerMoves的C#腳本，寫入程式碼，接著將此腳本掛載到剛剛建立的角色物件上。

### 3.執行測試：按下Play鍵執行，分三階段依序「向右平移 → 往右上斜飛 → 往右下俯衝」，抵達目標座標後自動停下。
